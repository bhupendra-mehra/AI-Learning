# Lesson 5 – Collections Module

The `collections` module provides specialized data structures that are often more convenient and efficient than basic Python structures.

We'll cover:

1. `Counter`
2. `defaultdict`
3. `deque`
4. `namedtuple`
5. `ChainMap`
6. Practical mini-project

---

# Quick Comparison

| Structure     | Main purpose                       |
| ------------- | ---------------------------------- |
| `Counter`     | Count items                        |
| `defaultdict` | Dictionary with automatic defaults |
| `deque`       | Fast queue                         |
| `namedtuple`  | Named tuple fields                 |
| `ChainMap`    | Combine multiple dictionaries      |
