# Why We're Slowing Down Here

Unlike loops, **functions are everywhere**.

For example, you've already used many functions without realizing it:

```python
print()
```

```python
input()
```

```python
int()
```

```python
float()
```

```python
range()
```

You know how to **use** them.

Now you'll learn how to **create** them.

This is one of the most important transitions in programming.
