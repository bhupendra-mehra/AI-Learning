# Step 2 – Creating the ATM Class

Now we'll create the heart of the application.

## Goal

Create an `ATM` class that stores the account balance.

Initially, we'll only create the class and constructor—no deposit or withdrawal methods yet.

```python
class ATM:

    def __init__(self):
        self.__balance = 5000
```

---

## Why `__balance`?

Remember **Encapsulation** from Lesson 11.

Instead of:

```python
balance = 5000
```

we use:

```python
self.__balance = 5000
```

Why?

Because the balance should **not** be modified directly from outside the class.

❌ Bad

```python
atm = ATM()

atm.__balance = 1000000
```

Anyone could change the balance.

✔ Good

```python
atm.deposit(500)

atm.withdraw(1000)
```

Only the class itself controls how the balance changes.

---

class ATM:

```python
atm = ATM()
```

Python automatically executes:

```python

```

and initializes the balance to **5000**.

# Interview Question ⭐

**Q. Why did we make `balance` private (`__balance`) instead of public?**

**Answer:**

Because the account balance should not be modified directly from outside the class. Making it private enforces encapsulation and ensures all balance changes go through controlled methods like `deposit()` and `withdraw()`, where business rules and validations can be applied.
