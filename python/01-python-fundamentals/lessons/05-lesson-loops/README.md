# Lesson 8 – Loops

**Objective:**
Learn how to execute the same block of code multiple times efficiently. By the end of this lesson, you'll be able to iterate through numbers, strings, and collections, control loop execution, and build interactive programs using loops.

**Estimated Duration:** 3–4 days (3–4 hours/day)

---

## Module 1 – Understanding Loops

**Estimated Time:** 30–45 minutes

### Topics

* What is a loop?
* Why loops exist
* Problems without loops
* Types of loops in Python
* `for` vs `while` (high-level overview)
* Execution flow
* Real-world examples
* PHP/Magento comparison
* AI Agent applications

### Practical Exercises

* Print your name 5 times
* Print numbers from 1 to 10

# Learning Outcomes

By the end of Lesson 8, you will be able to:

* Explain when and why to use loops.
* Use `for` and `while` loops confidently.
* Control loop execution using `break`, `continue`, and `pass`.
* Avoid infinite loops and common loop-related bugs.
* Solve repetitive programming tasks efficiently.
* Build interactive, menu-driven console applications.
* Understand how loops are used in Magento development (processing products, orders, customers) and AI agents (iterating over documents, API results, messages, and tool outputs).
