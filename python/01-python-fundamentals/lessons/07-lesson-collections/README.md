# Lesson 10 – Collections

**Objective:**
Learn Python collections to efficiently store, manage, and process multiple pieces of data. Collections are heavily used in AI, APIs, databases, and Magento development.

**Estimated Time:** **2.5–3.5 hours** (Fast Track)

---

# Lesson 10 Structure

## Module 1 – Lists

**Estimated Time:** 30–40 minutes

### Topics

* What is a List?
* Creating Lists
* Indexing (Positive & Negative)
* Update Items
* Add Items (`append`)
* Remove Items (`remove`, `pop`)
* List Length (`len`)
* Looping Through Lists
* Common List Methods (`sort`, `reverse`)
* Mini Exercises

**Mini Project**

* Product List Manager

---

## Module 2 – Tuples & Sets

**Estimated Time:** 30–40 minutes

### Topics

### Tuples

* What is a Tuple?
* Creating Tuples
* Accessing Values
* When to Use Tuples

### Sets

* What is a Set?
* Creating Sets
* Add & Remove Items
* Union & Intersection
* Duplicate Removal

**Mini Project**

* Student Registration System

---

## Module 3 – Dictionaries

**Estimated Time:** 40–50 minutes

### Topics

* What is a Dictionary?
* Key-Value Pairs
* Create Dictionary
* Read Values
* Update Values
* Add New Keys
* Remove Keys
* Loop Through Dictionary
* Nested Dictionaries
* Common Dictionary Methods

**Mini Project**

* Employee Information System

> **Note:** This is the most important module of Lesson 10 because AI APIs, JSON, and Magento REST responses are dictionary-based.

---

## Module 4 – Final Project

**Estimated Time:** 45–60 minutes

### Project

**Inventory Management System**

Features:

* Store Products
* Add Product
* Remove Product
* Update Quantity
* Search Product
* Display Inventory

**Concepts Used**

* Lists
* Dictionaries
* Loops
* Functions
* Conditions

---

# Learning Outcomes

By the end of Lesson 10, you'll be able to:

* Store multiple values efficiently.
* Choose the right collection (`list`, `tuple`, `set`, or `dictionary`).
* Process API responses.
* Work with JSON-like data structures.
* Build inventory-style applications.

---

# Where You'll Use This in AI Agent Development

| Collection | AI Usage                                            |
| ---------- | --------------------------------------------------- |
| List       | Chat history, search results, embeddings, documents |
| Tuple      | Fixed return values, coordinates, immutable data    |
| Set        | Remove duplicates, unique keywords, tags            |
| Dictionary | API responses, JSON, LLM outputs, tool results      |
