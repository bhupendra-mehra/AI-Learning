# Withdraw Method

```python
def withdraw(self, amount):

    if amount <= 0:
        raise InvalidAmountError(
            "Amount must be greater than zero."
        )

    if amount > self.__balance:
        raise InsufficientBalanceError(
            "Insufficient Balance."
        )

    self.__balance -= amount

    print("Withdrawal Successful")
```

# Current ATM Class

```python
class ATM:

    def __init__(self):
        self.__balance = 5000

    def deposit(self, amount):

        if amount <= 0:
            raise InvalidAmountError(
                "Amount must be greater than zero."
            )

        self.__balance += amount

        print("Deposit Successful")

    def withdraw(self, amount):

        if amount <= 0:
            raise InvalidAmountError(
                "Amount must be greater than zero."
            )

        if amount > self.__balance:
            raise InsufficientBalanceError(
                "Insufficient Balance."
            )

        self.__balance -= amount

        print("Withdrawal Successful")
```

# Real Magento Example

This pattern is exactly how business validation is implemented.

```php
if ($qty <= 0) {
    throw new InputException(
        __("Quantity must be greater than zero.")
    );
}

if ($qty > $availableQty) {
    throw new LocalizedException(
        __("Insufficient Stock.")
    );
}
```

Notice the similarity:

| Python                                | Magento/PHP                         |
| ------------------------------------- | ----------------------------------- |
| `raise InvalidAmountError(...)`       | `throw new InputException(...)`     |
| `raise InsufficientBalanceError(...)` | `throw new LocalizedException(...)` |

The language changes, but the design pattern remains the same.

# Interview Questions

### Q1. Why do we validate `amount <= 0` before checking the balance?

**Answer:**

Because an invalid amount should be rejected immediately. There's no point checking the account balance if the input itself is invalid.

---

### Q2. Why is the balance private?

**Answer:**

To enforce encapsulation. The balance should only be modified through controlled methods like `deposit()` and `withdraw()`, where validation and business rules are applied.
