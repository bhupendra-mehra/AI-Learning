# Deposit Method

```python
def deposit(self, amount):

    if amount <= 0:
        raise InvalidAmountError(
            "Amount must be greater than zero."
        )

    self.__balance += amount

    print("Deposit Successful")
```

class InvalidAmountError(Exception):

class InsufficientBalanceError(Exception):
    pass


class InvalidChoiceError(Exception):

class ATM:

    def __init__(self):
        self.__balance = 5000

    def deposit(self, amount):

        if amount <= 0:
            raise InvalidAmountError(
                "Amount must be greater than zero."
            )

        self.__balance += amount

        print("Deposit Successful")


atm = ATM()

# Why Don't We Write

```python
self.__balance = amount
```

Imagine

```text
Balance = 5000

Deposit = 1000
```

Then

```python
self.__balance = amount
```

makes

```text
Balance = 1000
```

❌ Wrong.

We want

```python
self.__balance += amount
```

which becomes

```text
5000 + 1000 = 6000
```

✔ Correct.

# Interview Question ⭐

### Q1. Why do we use

```python
+=
```

instead of

```python
=
```

**Answer**

Because a deposit **adds** money to the existing balance instead of replacing the balance.

---

### Q2. Why do we validate before updating the balance?

**Answer**

To ensure invalid data never changes the object's state. If validation fails, an exception is raised and the balance remains unchanged.
